# References — After the Signal

Reviewed local source: 2026-11-15. Public link availability is recorded separately in REFERENCES-CHECK.md. This inventory records actual uses, not a claim of NASA endorsement or global eligibility.

## NASA datasets and tools

- [NSSDCA](https://nssdc.gsfc.nasa.gov/): Curated spacecraft and mission history. A challenge-listed resource in the challenge text supplied by the project owner.
- [NASA Image and Video Library API](https://images.nasa.gov/docs/images.nasa.gov_api_docs.pdf): Image selection, image identifiers, captions and attribution. Local documentary assets avoid initial API delays.
- [JPL Horizons API](https://ssd-api.jpl.nasa.gov/doc/horizons.html): Dated trajectory and light-time model calculations. Not live radio telemetry.
- [InSight weather API documentation](https://api.nasa.gov/assets/insight/InSight%20Weather%20API%20Documentation.pdf): Optional archival Mars weather feed. Unavailability triggers labelled reference data.
- [NASA SVS CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/): LRO/LROC Moon mosaic behind interactive flags.
- [NASA Mars Trek](https://trek.nasa.gov/tiles/apidoc/trekAPI.html?body=mars): NASA/USGS Viking MDIM 2.1 global Mars mosaic.
- [Mars map capabilities](https://trek.nasa.gov/tiles/Mars/EQ/Mars_Viking_MDIM21_ClrMosaic_global_232m/1.0.0/WMTSCapabilities.xml): Provenance and geographic tile coverage of the Mars background.
- [NASA images and media guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/): Attribution and third-party rights guidance. NASA endorsement is not claimed.
