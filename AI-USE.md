# AI use and provenance — After the Signal

**Tools used:** [Claude by Anthropic](https://www.anthropic.com/claude) and [OpenAI Codex](https://openai.com/codex/). Exact model versions were not consistently recorded and are not invented here.

AI assisted code, CSS, generic interface graphics, fictional narrative drafting, source/image selection, debugging, documentation and revision. The project owner provided direction, requirements, assets and iterative feedback. The team roster does not establish individual production roles.

## What the visitor sees

- First-person stories and terminal emergencies are fictional editorial devices. They are not literal messages from spacecraft.
- Mission facts and documentary photographs reference NASA records. AI assisted their curation and descriptions, not the creation of NASA observations.
- JPL Horizons values are dated model results. Mars weather is archival. Fallback values are labelled reference data or historical examples. The 15-second battery is a simulation.
- Web Audio oscillators synthesize fictional terminal sounds through AI-assisted code. There is no generative speech voice or recorded spacecraft audio.
- The hero uses MisterH's artist-made model, rendered into compressed looping video. Its author, CC BY 4.0 licence and adaptation are credited. No generative image/video model produced that asset.
- The UNIFEI logo was supplied by the project owner and is displayed unchanged. It does not assert institutional sponsorship.

## Metadata included in the deliverable

- [public/ai-disclosure.json](public/ai-disclosure.json): structured, project-specific disclosure for source code, writing, reference data, sound and visual assets.
- `index.html`: author and AI-assistance metadata, with a `describedby` link to the JSON disclosure.

These are project-specific metadata fields and sidecar records, not a claim that the hackathon mandates a particular metadata standard. The public folder is copied into the production build, so its metadata travels with the deployed site. The code archive includes the same records.
